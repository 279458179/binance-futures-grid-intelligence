## 风险登记
| 风险 | 影响 | 缓解 |
|---|---|---|
| Binance API 地区/流量受限 | 扫描失败 | 合规选择数据来源/部署地区，明确 PARTIAL，不绕限制 |
| 4H 趋势与 4h 计划有效期混淆 | 时序错判 | UTC 时间窗及 4H/1H/15M 职责分工 |
| 分数被误称预测概率 | 决策偏差 | UI 明示分数不是胜率 |
| OHLCV 无法确定同根 K 线成交先后 | 网格 PnL 过于乐观 | 细粒度数据或保守撮合模型 |
| OI/taker 历史不足 | 假精确 | N/A、覆盖率降级 |
| 低流动性、滑点和 minNotional | 计划不可执行 | 流动性/费用/精度硬闸门 |
| 2C2G 计算资源不足 | OOM/延迟 | 分层扫描、压测、必要时升级 |
| 高频提醒导致过度交易 | 风险上升 | NO_TRADE 优先、去重和冷却 |
| 高杠杆导致迅速强平 | 资金损失 | >5x 不出可执行建议，严格预算与止损 |
