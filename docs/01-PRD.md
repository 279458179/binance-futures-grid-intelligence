# 01｜产品需求说明书（PRD）

**版本** 1.0.0 | **状态** 已完成规格说明，待实现 | **系统类型** Binance 永续合约方向研判 + 人工网格辅助

## 1. 背景与问题

主观盯盘容易因为短周期假突破、冲高回落、插针而追多/追空；合约网格常见问题是：中性网格遇单边行情承受仓位浮亏，方向网格入场滞后、区间定得过宽/过窄、手续费吞噬每格利润，且很难同时考虑 BTC/ETH、OI、主动买卖和流动性风险。

### 业务目标（优先级由高到低）
1. 及时识别 `NO_TRADE` 并解释理由，防止为了凑数而产生错误网格。
2. 识别未来最多 4h 内值得关注的 LONG/SHORT 方向网格机会。
3. 使用**可核验的触发条件**，不以单根未收盘 K 线下结论。
4. 输出风险预算内的网格与进出场参数，区分行情价、触发价、启动价、止损价。
5. 记录每次方案并复盘信号质量，不依靠“主力控盘”的不可验证叙述。

### 明确不做（初始版本）
- 真实自动交易、实盘 API Key、合约持仓同步、任何委托写入。
- 承诺正确率、收益率、保本，或者基于少量测试就公布“高胜率”。
- 通过规避地区访问限制获取平台能力；用户应遵守当地法律和交易所规则。
- 依赖付费强平热力图供应商才能运行；它只是后续的可选来源。

## 2. 用户角色

- Owner：个人自用管理员，控制策略参数、提醒规则、部署和备份。
- Read-only viewer（可选）：只能看信号，不可改变全局策略或风险设置。
- Worker：内部后台任务身份；不能调用 Binance 交易端点。

## 3. 核心业务旅程

### A. 全市场扫描
点击“立即扫描”→系统检查可用数据与时间→BTC/ETH 基准研判→交易所合约资格/流动性过滤→60–100 个候选多周期粗筛→20–30 个候选的订单流和衍生品深化→多空评分与风险闸门→最佳 0–5 个 LONG、SHORT、RANGE 候选（不凑数）→理由/失效条件/下次观察条件。

### B. 单币深度分析
输入 `BTCUSDT` → 4H/1H/15M/可选5M 图、关键水平支撑压力、前高前低、双顶双底、扫单/SFP/假突破、EMA/MACD/RSI/ADX/ATR/RVOL、OI、CVD 近似、主动买卖、资金费率、资金拥挤；同时标记数据来源和 UTC 时间戳。

### C. 生成方向网格
方向通过评分和硬闸门→确定入场状态：`ENTER_ON_CONFIRMATION` / `WAIT_PULLBACK` / `WAIT_BREAKOUT_CLOSE` / `WAIT_SWEEP_CONFIRMATION` / `WATCH_ONLY` / `NO_TRADE`→可输入策略资金与费率参数→计算网格上下限、数量、几何/等差间距、启动价、止盈/止损、失效位、风险收益比、预期订单最小名义金额→人工复核→复制参数到交易所手动设置。若不能确认交易所原生 Bot 的启动机制，启动价必须标记“待核验”，不能误导填单。

### D. 方案失效与提醒
每根 15M K 线完成后重新评估指定观察池（后台运行配置后）：若触发价条件真正成立/失效、价格偏离原快照 >1×15M ATR、4H/1H 结构冲突、BTC/ETH 大盘翻转或盘口流动性恶化，则标记 `STALE` 或 `INVALIDATED`；前端显示新旧方案的差异。通知去重、冷却、记录发送结果。

### E. 回测与复盘
对每个策略版本做逐根 K 线历史重放，模拟 15M 确认时点才能下发信号；包含费率/滑点/资金费率、订单是否可成交、网格库存盈亏；每日统计信号后 4h 的 MFE/MAE、胜负、实际触发率、回撤、收益分布。先回测、再纸面模拟、再人工复核。

## 5. 非功能与质量（NFR）

| ID | 标准（MVP 初始目标，可在实测后调整） |
|---|---|
| NFR-001 | API 服务可用、可健康检查、可观测；目标 99% 自托管可用性（不保证云商/SLA） |

| NFR-008 | 前端移动端首屏可读；默认暗色专业交易台、颜色兼顾无障碍 |

## 6. 设计评估成功标准

- 正确性：与 Binance 源数据时间对齐、已收线指标可重复；单元/集成测试通过。
- 行为：当信号不足或风险过高，返回 NO_TRADE；不靠增加杠杆获得表面高收益。
- 交易价值：只有在滚动样本外回测中，净结果和最大回撤同时达到事前设定阈值，才可认为一个策略配置可继续研究；绝不提前承诺达到阈值。
- 可操作性：任一 GRID_PLAN 都能解释“为什么”“何时有效”“何时失效”“什么成本和损失可能发生”。

## 7. 发布边界

MVP = 只读真实数据采集 + 基础评分/结构识别 + 方案生成（模拟参数）+ 静态/JSON 报告 + 本地可测试。Web、后台常驻、外部提醒、正式回测工具按里程碑逐步交付。**本仓库当前只有需求与计划，不是可运行产品。**
