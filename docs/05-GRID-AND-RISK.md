# 05｜方向网格与风控合同

## 模式选择
- 4H/1H 多头一致，15M 回踩/下扫收复确认：LONG_GRID。
- 4H/1H 空头一致，15M 反弹失败/上扫确认：SHORT_GRID。
- 只有双侧区间反复确认、ADX 低且 ATR 稳定：NEUTRAL_GRID。
- 单边突破、ATR/成交量爆发或清算冲击：WAIT/NO_TRADE；剧烈波动绝不自动归为中性。
- 数据、资金、费率、合约规则缺失：WATCH/PARTIAL/NO_TRADE。

## 参数语义必须分开
`signal_trigger` 是收线/回踩/结构条件；`activation_price` 是 Binance 原生 Bot 启动价（必须核对官方 UI/API 语义）；`entry_zone` 是人工认可入场价格带；`grid_lower/upper` 是结构化网格边界；TP1/TP2 是目标；SL/invalidation 是假设失效位置。若平台不能原生表达止损或启动语义，明确标记需要人工管理，不能误导为已设置。

## 网格与成本
几何网格 ratio=(upper/lower)^(1/N)，单格毛比例=(ratio-1)；等差网格 delta=(upper-lower)/N。回合成本包括双边手续费和滑点，另计资金费率。单格净间距≤0 直接拒绝；可验证费率下建议毛间距至少为回合成本 2.5 倍，再由回测校准。必须核验 tickSize、stepSize、minQty、minNotional、挂单数与保证金约束。费率未知只给场景范围，不给伪精确净收益。

## 资金与杠杆政策
默认 2–4x，5x 仅经额外风险校验；>5x 不生成可执行建议。小额账户建议保留 30%–45% 储备金，单机器人权益占用上限 55%–70%，相关品种合并计算风险。资金未知时不得给精确订单量、强平价或最大亏损 USDT。单日机器人损失上限默认不超过权益 6% 与用户限额中的较严值。默认逐仓，关闭自动追加保证金。精确强平价必须依赖真实仓位、维持保证金、手续费和标记价。

## 拒绝闸门
数据/收线不合格；4H/1H冲突；盘口/流动性不合格；BTC/ETH强反向；funding/OI过度拥挤；追价过度延伸；当前价已离开网格；资金、费率、最小名义额或风险预算未知；止损无法实施；用户要求不合理杠杆。任一触发则不通过。

## 输出要求
输出 LONG_GRID_PLAN / SHORT_GRID_PLAN / NEUTRAL_GRID_PLAN / WATCH / NO_TRADE，附评分证据、触发条件、有效期、启动价与入场区间、上下限、格数、费率假设、TP/SL、失效条件、资金预算和回测状态。已实现网格利润、未实现库存损益、手续费和资金费率分开核算。
